# cypher-tck

openCypher TCK v1 conformance harness for the
[cyrs](https://github.com/phall1/cyrs) frontend. Runs the tagged subset of
the openCypher Technology Compatibility Kit against `cypher-db` and gates
every PR. See spec 0001 §17.5.

For the full story — architecture, dependency graph, and testing bar — see
the [repo-root README](https://github.com/phall1/cyrs#readme).
