# cypher-diag

Stable diagnostic codes (`E0001`..., `W6000`..., `N8000`...) and rendering
backends (plain text, codespan, LSP) for the Cypher / GQL frontend. See
spec 0001 §10.

For the full story — architecture, dependency graph, and testing bar — see
the [repo-root README](https://github.com/phall1/cyrs#readme).
