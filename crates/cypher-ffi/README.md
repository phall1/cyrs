# cypher-ffi

[![crates.io](https://img.shields.io/crates/v/cypher-ffi.svg)](https://crates.io/crates/cypher-ffi)
[![docs.rs](https://img.shields.io/docsrs/cypher-ffi)](https://docs.rs/cypher-ffi)
[![CI](https://github.com/phall1/cyrs/actions/workflows/ci.yml/badge.svg)](https://github.com/phall1/cyrs/actions/workflows/ci.yml)
[![MSRV](https://img.shields.io/badge/MSRV-1.94-blue)](https://github.com/phall1/cyrs/blob/main/rust-toolchain.toml)
[![License: Apache-2.0 OR MIT](https://img.shields.io/badge/license-Apache--2.0%20OR%20MIT-blue.svg)](#license)

Stable C ABI over the Cyrs Cypher / GQL frontend.  Ships a `cdylib` +
`staticlib` that embedders from Go, Java (JNI), Node (N-API / `koffi`),
Swift, and C link directly.  Thin adapter over `cypher-lang-services` +
`cypher-db` + `cypher-diag` + `cypher-fmt`; no analysis logic lives here
(spec 0004 §5).

## Build

```bash
cargo build -p cypher-ffi --release
```

Produces (relative to the workspace target directory):

| Artifact                                | Target                            |
| --------------------------------------- | --------------------------------- |
| `target/release/libcypher_ffi.dylib`    | macOS                             |
| `target/release/libcypher_ffi.so`       | Linux                             |
| `target/release/cypher_ffi.dll`         | Windows                           |
| `target/release/libcypher_ffi.a`        | All (static archive for linking)  |

## Header

The authoritative C header lives at
[`crates/cypher-ffi/include/cypher.h`](include/cypher.h) and is
regenerated by `cargo xtask cbindgen`:

```bash
# regenerate the committed header
cargo xtask cbindgen

# verify committed header matches regeneration (CI gate, spec 0004 §5.6)
cargo xtask cbindgen --check
```

Install `cbindgen` once per workstation:

```bash
cargo install cbindgen --locked
```

If `cbindgen` is not on PATH the `--check` subcommand skips with a clear
message — local developers are not blocked by missing tooling; CI runners
install it and treat the skip path as a failure so the byte-for-byte
header contract holds in aggregate.

## ABI commitment

Once a symbol ships in a tagged release of `cypher-ffi`, its signature
and semantics are frozen for the life of the major version (spec 0004
§9.2).  New symbols may be added in minor releases.  Symbol removal or
signature change requires a major bump and a CHANGELOG entry.

The source of truth for "the ABI" is the committed `include/cypher.h`
plus the published version number on crates.io.  `cargo xtask cbindgen
--check` catches C-side drift; `cargo-semver-checks` catches Rust-side
drift.

## Memory-ownership contract (spec 0004 §5.2)

Every pointer this library returns must be freed via the **paired**
`cypher_<name>_free` function.  Mixing allocators (e.g. calling `free()`
on a pointer this library allocated) is undefined behaviour.

| Returns                          | Free with                            |
| -------------------------------- | ------------------------------------ |
| `cypher_database_new`            | `cypher_database_free`               |
| `cypher_check`                   | `cypher_diagnostic_list_free`        |
| `cypher_parse`                   | `cypher_parse_result_free`           |
| `cypher_format`                  | `cypher_string_free`                 |
| `cypher_rewrite`                 | `cypher_rewrite_result_free`         |
| `cypher_hover`                   | `cypher_hover_result_free`           |
| `cypher_complete`                | `cypher_completion_list_free`        |
| `cypher_plan_text`               | `cypher_string_free`                 |

Accessor functions that return `const char*` (e.g.
`cypher_diagnostic_code`) return a **borrowed** pointer whose lifetime
is tied to the owning opaque container; the caller must not `free` it.
The pointer is valid until the container is passed to its `_free`.

`cypher_last_error()` returns a pointer into thread-local storage.  It
never returns `NULL`; when no error has occurred it points at the empty
string `""`.  Do not free it.

## Panic boundary (spec 0004 §5.3)

Every export wraps its body in `std::panic::catch_unwind` and converts
any panic to:

1. A `NULL` / `0` return value signalling failure.
2. A thread-local error string readable via `cypher_last_error()`.

No panic ever crosses the FFI boundary.  The workspace release profile
sets `panic = "abort"`, which reduces `catch_unwind` to a no-op in
release builds — the process aborts on panic rather than returning
control.  Abort is still safe across `extern "C"`: the invariant is
that an unwind never escapes to the caller, which holds under either
panic strategy.  Dev / test profiles default to `unwind` so
`tests/panic_safety.rs` exercises the catch path end-to-end.

## `unsafe` waiver (spec 0004 §5.4)

Spec 0001 §17.13 pins `#![forbid(unsafe_code)]` workspace-wide.  This
crate is granted a crate-local exception because the ABI requires
raw-pointer handling at the export boundary.  In this crate:

- `unsafe_code = "allow"` is set at the `[lints.rust]` table in
  `Cargo.toml`, not with a blanket `#![allow(unsafe_code)]` attribute.
- Every `unsafe` block carries a `// SAFETY:` comment documenting the
  caller invariants the block relies on (rust-analyzer house style,
  spec 0001 §23).
- `unsafe_op_in_unsafe_fn = "deny"` keeps `unsafe fn` bodies explicit.
- No `unsafe` is used for performance; every occurrence is load-bearing
  for the ABI.

The waiver does not extend to any other crate.

## Example — C

```c
#include "cypher.h"
#include <stdio.h>
#include <string.h>

int main(void) {
    CypherDatabase* db = cypher_database_new();
    const char* src = "MATCH (n RETURN n";   // unclosed paren
    CypherDiagnosticList* list = cypher_check(db, src, strlen(src));

    size_t n = cypher_diagnostic_list_len(list);
    printf("%zu diagnostic(s):\n", n);
    for (size_t i = 0; i < n; ++i) {
        const char* code = cypher_diagnostic_code(list, i);
        const char* msg  = cypher_diagnostic_message(list, i);
        printf("  %s: %s\n", code, msg);
    }

    cypher_diagnostic_list_free(list);
    cypher_database_free(db);
    return 0;
}
```

Link with `-lcypher_ffi` and `-L <workspace>/target/release`.
